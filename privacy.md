# Privacy Policy for Liebe
**Last Updated:** November 28, 2026

This Privacy Policy explains how **Liebe** ("the Bot"), created by **Not Gamer**, handles your data on Discord.

## 1. Data We Collect
To provide AI conversations, mini-games, and moderation features, the Bot may temporarily process or store:
* **Discord IDs:** User IDs, Server (Guild) IDs, and Channel IDs (for game stats, achievements, moderation logs, and command cooldowns).
* **Minigame records:** Per-server game counts, wins, losses, draws, game-specific totals, and achievement unlocks. These records are stored to provide profiles, achievements, and server statistics.
* **AI memory summaries:** The Bot may extract a short summary of potentially useful lasting context from AI-chat messages and store it against that user ID and server ID to personalize later replies.
* **Message Content:** Messages sent directly to or mentioning the Bot for AI conversation responses.

## 2. How We Use Data
Collected data is used strictly to:
* Generate AI replies during active conversations.
* Track game results, profiles, achievements, and server statistics.
* Execute moderation actions requested by server administrators.

## 3. Data Storage & Third-Party Services
* AI prompts may be processed through third-party AI providers solely to generate responses.
* We do **not** sell, rent, or share your personal data with third parties for marketing.
* Full AI-chat message content is not permanently stored after a response is generated. A separate concise memory summary may be retained as described above.

## 4. Data Deletion
You may request deletion of stored game stats, achievements, AI memory summaries, or server data by contacting **Not Gamer** (`notgamer__69`) on Discord.


## Server logging and tickets
When administrators enable Liebe logging, the bot may record deleted and edited guild messages, including available text, attachment links, embed links, and forwarded-message snapshots, in the configured message-log channel. Command and moderation usage/error metadata may be recorded in the configured mod-log channel. Ticket data such as ticket owner, category, channel ID, and open/closed status is stored to operate the ticket system. Server administrators control these features and should configure access to log channels carefully. Discord may not provide content for messages deleted before Liebe cached them.
